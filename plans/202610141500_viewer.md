# Viewer

**Status:** Done

Implements [specs/viewer.md](../specs/viewer.md): a naoqi-viewer mirror window on the robot the bridge drives, configured by a `viewer` block, opened last at `start()` and closed first at `stop()`, skipped with a warning on `fake` and on a sim that shows its own window. It also builds the spec changes it implied in [config.md](../specs/config.md), [bridge.md](../specs/bridge.md), [project.md](../specs/project.md), [testing.md](../specs/testing.md) and both server specs. It leaves out the spec's open questions (a viewer on the fake, reopening a closed window, a second window on a borrowed sim).

## Scope

- `pyproject.toml`: the `[viewer]` extra (`naoqi-viewer` with `qi`'s marker), naoqi-viewer's git source pinned to naoqi-sim's commit, `naoqi-bridge[sim,viewer]` in the dev group; `uv.lock` relocked
- `src/naoqi_bridge/config.py`: `ViewerSettings` (`enabled`, `config`), `NaoqiBridgeConfig.viewer`, the three refused fields, naoqi-viewer's errors under `viewer.config.`, the missing-extra rule
- `src/naoqi_bridge/errors.py`: `ViewerError(BridgeError)`
- `src/naoqi_bridge/viewer.py` (new): `viewer_target`, `open_viewer` (cancel-safe), `close_viewer`
- `src/naoqi_bridge/bridge.py`: open the viewer at the end of the bring-up, close it first on teardown and `stop()`
- `src/naoqi_bridge/__init__.py`: export `ViewerSettings`, `ViewerError`
- `src/naoqi_bridge/naoqi_mcp_server.py`, `naoqi_websocket_server.py`: a `ViewerError` at start is a failed start (CLI exit 1)
- `examples/configs/mcp-real.json`, `websocket-real.json`: a disabled `viewer` block with the ghost on
- `tests/test_config.py`: the `viewer` block's rules
- `tests/test_viewer.py` (new): `viewer_target`'s table, the lifecycle against a stub `NaoqiViewer`, the server's failed start
- `tests-e2e/test_live_viewer.py` (new): the window opens and closes with a bridge, behind `NAOQI_E2E_VIEWER`
- `AGENTS.md`: the `viewer.py` row in the project map; `specs/viewer.md` frontmatter naming the new files

## Steps

1. **Packaging.** Add `viewer = ["naoqi-viewer; <qi marker>"]` to `[project.optional-dependencies]`, `naoqi-viewer = { git = "https://github.com/funwithagents/naoqi-viewer", rev = "<naoqi-sim's pin>" }` to `[tool.uv.sources]` with a comment saying the two pins move together, and `naoqi-bridge[sim,viewer]` in the dev group. `uv lock`, checking the lock still holds one naoqi-viewer.
2. **Config.** `VIEWER_EXTRA`, `viewer_installed()` and a `naoqi_viewer.config` reader beside the sim ones: refuse `mode`, `headless` and `naoqi.url` in the raw block (key under the block's path, "is set by the bridge"), then `NaoqiViewerConfig.from_dict`, re-raising its `ConfigError` with the prefix; `None` when naoqi-viewer is missing. `ViewerSettings(enabled=False, config=None)` and `NaoqiBridgeConfig.viewer`; `__post_init__` refuses `viewer.enabled` on `real` or `sim` without naoqi-viewer (key `viewer.enabled`, naming the extra).
3. **`ViewerError`** in `errors.py`.
4. **`viewer.py`.** `viewer_target(config, lease)` applies the spec's table, logging the two skips at `WARNING`; it reads "a sim with its window" as an owned lease whose `naoqi_sim_config(config.sim).viewer.headless` is false. `open_viewer(settings, url)` builds the `NaoqiViewerConfig` with `mode="mirror"`, `headless=False` and the URL, launches it in a thread, waits for that launch through a cancel and closes the viewer before re-raising; a `LaunchError` becomes `ViewerError`, chained. `close_viewer` closes in a thread and logs a failure.
5. **Bridge.** `_bring_up` takes the lease and, after the catalog, opens the viewer when `viewer_target` gives a URL, keeping it on `self._viewer`, so a failed or cancelled bring-up already tears it down. `_teardown` and `_shut_down` close it first.
6. **Front door and servers.** Export the two names; both servers catch `ViewerError` beside `RobotConnectionError` at start.
7. **Examples.** The disabled `viewer` block in the two `real` files.
8. **Tests.** Fast: config rules (each refused field, the prefix, the missing extra per backend, a disabled block on fake), every row of `viewer_target`'s table with its warning, the bridge on `real` with a stub viewer (opened after the robot connects with the robot's URL, closed before the robot on `stop()`, a `LaunchError` as `ViewerError` with the robot closed, a cancel during the launch closing the viewer), the websocket server's failed start. Live: `test_live_viewer.py` skips without `NAOQI_E2E_VIEWER`; with it, a bridge on the target opens the window and `stop()` closes it.
9. **Map and statuses.** The project-map row, the spec's frontmatter; once verified, every spec this touched back to `Implemented` and this plan `Done`.
